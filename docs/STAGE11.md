# 阶段十一 · Windows 桌面工作台

## 启动

双击发布目录里的 `EasyWriting.exe` 进入原生窗口。发布目录中的 `_internal` 需要和 EXE 放在一起。默认数据目录为 `%LOCALAPPDATA%\EasyWriting`。

- 点击 **创建离线演示作品** 可以直接体验样章、问答、下一章路线和检查报告。
- **项目导入** 支持预览、校订和确认导入单章 Word、PDF、TXT 或 Markdown。对扫描页可启用本地 OCR。
- **知识查看** 提供人物、事件、伏笔、出处、两种时间线和人物关系。**创作问答** 保存会话，支持截止章、人物视角、深度对话及可选语义摘要。
- **下一章路线** 按编号和标题分隔同一份草稿中的候选方案。可在「定位或选择路线」中跳到指定方案，再点击「采纳所选路线」。
- **数据与设置** 可打开已有小说知识库和独立会话库，分别备份、恢复，或导出当前作品知识。恢复写入新文件，之后可选择该文件继续使用。

## 沿用已有项目

在 **数据与设置** 分别选中已有的两个数据库文件，再点击 **应用路径并打开数据库**。对于仍含旧版会话的知识库，程序沿用阶段九的迁移与备份流程。界面保存选取的路径，便于下次启动。

## 模型与 OCR

- DeepSeek 读取用户数据目录中的 `.env`，也可在 **数据与设置** 选用已有本机配置。相对路径以配置文件所在目录为基准。选择 **DeepSeek** 并提交时，本轮相关资料会发送至配置的接口。
- OCR 引擎随发布包提供，语言数据由本机配置。默认语言为简体中文和英文。可设置 `OCR_TESSDATA_PATH`，或选用已配置 OCR 的项目 `.env`。识别结果会在 PDF 预览中标记，确认前可校订。详见 [阶段十](STAGE10.md)。
- 本地 BGE 为可选项。先在项目 Python 环境安装 `.[semantic]`，准备本地模型缓存。在 **数据与设置** 选择该环境的 `python.exe` 并应用，然后在问答页勾选 **本地 BGE**。例如可选择项目的 `.venv\Scripts\python.exe`。基础包内置关键词检索，BGE 由选定的本机运行时执行。

## 构建

在 Windows 项目根目录执行以下命令。构建解释器需能创建 Tk 窗口。

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[desktop-build,ocr]'
.\scripts\build_desktop.ps1
```

发布目录为 `dist/EasyWriting`。本地调试可运行 `python -m easy_writing.desktop`。使用 `--data-dir` 可以指定独立的验收数据目录。
