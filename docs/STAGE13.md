# 阶段十三 · 按作品分库与会话管理

运行 `dist/stage13/EasyWriting/EasyWriting.exe`。如果要移动发布包，请保留整个 `EasyWriting` 目录。也可以从项目根目录运行 `python -m easy_writing.desktop`。

## 作品目录

默认作品根目录为 `%LOCALAPPDATA%\EasyWriting\works`。可以在「数据与设置 → 作品根目录」选择另一处目录，再点击「应用路径并打开作品目录」。切换路径会打开所选位置的作品列表。搬移作品时需关闭桌面版，并随作品目录保留 `work.json` 和两个数据库。

| 内容 | 位置 |
| --- | --- |
| 作品标识与库绑定 | `<作品 ID>/work.json` |
| 正文版本、人物、事件、伏笔、证据、检查报告和路线 | `<作品 ID>/easy_writing.db` |
| 问答、逐轮记忆、滚动摘要和会话用量 | `<作品 ID>/easy_writing_chat.db` |
| 可恢复的已删除作品 | `.recycle/<作品 ID>/` |
| 迁移时保存的旧库快照和校验清单 | `.migration-backups/<备份 ID>/` |

新建作品和创建离线演示作品都会自动建库。在顶部选中作品后，可在「数据与设置」重命名或删除。重命名保留作品 ID 和目录。删除会将整个目录移入应用内回收站，可用「恢复回收站作品」恢复。

在「创作问答」选中会话后，可重命名或删除该会话。同名会话在列表中有不同序号，删除确认框显示稳定会话 ID 的前八位。删除会清除该会话的问答、引用、记忆、摘要和用量，已有备份仍可保留相应历史。

## 从共享旧库迁移

1. 关闭旧版应用。打开新版，在「数据与设置」设置作品根目录。
2. 点击「迁移旧库／导入备份」，依次选择旧小说知识库和配套的独立会话库。只拥有旧小说知识库时，可以在跳过会话库的确认框中继续。
3. 查看已迁移、已处理、失败的作品以及备份目录。源文件会保留，迁移后的作品可直接从顶部下拉框打开。

迁移先备份再按作品复制，核对表行数、外键和数据库完整性。章节、版本、路线、证据及会话标识保留，目标会话库绑定到新的知识库标识。旧版内嵌会话会在工作副本中转入独立会话库。迁移失败的作品可用原文件重试，已处理的作品会跳过。需要恢复单库备份时，「恢复到新文件」用于提取独立文件，随后可通过迁移入口导入配套的两个备份。

## 验收

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\scripts\build_desktop.ps1 -DistPath 'dist/stage13'
```

全量自动测试共 294 项通过，覆盖作品隔离、重开、重命名、回收与恢复、按 ID 删除同名会话及其记忆、取消删除、进行中摘要的删除保护，以及双库迁移失败后重试。打包版在临时数据目录通过 17 项离线自检，包括 Word/PDF 导入、本地 OCR 和本地 BGE。
