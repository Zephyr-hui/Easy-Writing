# 阶段十四 · 作品写作设定与下一章草稿

打开 `dist/stage14-settings/EasyWriting/EasyWriting.exe`。移动发布包时请保留整个 `EasyWriting` 目录。

## 编辑两套写作要求

点击目标或约束的预览框打开多行编辑弹窗。编辑期间主窗口暂停操作。「保存」提交当前内容，「取消」或按 Esc 放弃编辑。

| 入口 | 作用范围 | 保存方式 |
| --- | --- | --- |
| 创作问答的作品目标、作品约束 | 例如全书节奏、角色塑造方向、固定叙事视角。每项最多 1200 字。 | 保存在当前作品的独立会话库。切换会话时保留，切回作品或重启时恢复。要清空某项，请保存空白内容。 |
| 下一章路线的本章目标、本章约束 | 例如本章的冲突和暂缓揭晓的线索。目标最多 1200 字，约束按行填写，最多 8 条且每条最多 1200 字。 | 本章输入供生成路线和正文使用。生成候选路线和采纳时保留，成功提交正文生成或切换作品时清空。 |

会话问答历史继续按会话保存。修改作品级设定后，模型使用当前设定，旧设定下的创作建议与摘要保留在历史中供作者查看。

## 生成下一章标题与正文

1. 在「下一章路线」生成或打开一份路线，选中其中一条，点击「生成下一章内容」。可直接使用选中的路线。
2. 确认章号和路线。通过校验后，程序先保存本次的本章要求、路线及模型模式，再开始生成。
3. 成功后可在草稿下拉框打开结果，查看或复制标题与正文。草稿随作品保存。要将它成为正式正文，请在「项目导入」中校订、确认和提取知识。
4. 模型出错或截断时，可选中失败记录并点击「重试章节生成」，沿用原请求。路线依据已变化时，需要重新生成路线。程序中断时，进行中的草稿在提交运行满 30 分钟后可重试。

离线演示使用固定样稿模板。DeepSeek 使用当前的分析模型设置，章节输出预算从 8192 token 起，可通过本机配置中的 `LLM_MAX_OUTPUT_TOKENS` 调高。选择 DeepSeek 并提交后，本章要求及相关小说资料会发送到配置的接口。

## 从阶段十三升级

关闭旧版后打开新版，同一个作品目录继续使用。首次打开作品时，小说库升级到 v10，会话库升级到 v2，原有小说及会话数据随库保留。原作品首次升级后请使用新版打开。

阶段十四通过 296 项自动测试和 20 项发布包离线自检。数据库升级使用阶段十三发布包的测试库副本验证，章节草稿生成使用离线模板与模拟错误响应验证。
