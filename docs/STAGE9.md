# 阶段九 · 长上下文压缩与独立会话库

## 会话库与迁移

更新后先关闭旧版工作台，再启动新版。默认会在小说知识库同目录创建 `easy_writing_chat.db`。可在工作台左侧选择会话文件，或设置 `CHAT_DATABASE_PATH`。

小说知识库升为 v8，记录稳定的库标识。独立会话库保存完整问答、逐轮记忆、滚动摘要、对话任务状态和用量。作品和会话以库标识隔离。答复中的证据关联保存为定位信息，正文和检索原文由知识库提供。

打开有阶段八会话的知识库时，工作台会生成 `.pre-chat-split-*.bak` 备份，将对话迁入独立会话库，逐条验证后才清理旧工作库中的对话记录。迁移可重跑，冲突时保留原记录。可在 **项目导入 → 改稿与数据维护** 分别备份或恢复小说知识库和会话库。恢复到新文件后，在左侧选择对应文件即可。恢复同一作品的聊天时，使用该作品的知识库或其备份副本。

## 逐轮记忆和上下文压缩

每轮保存答复后，默认在本机提炼本轮主题、作者目标和约束、已讨论的方案、待核查事项及出处。滚动摘要按会话、主题、章节范围、人物视角、故事时点和知识快照隔离。最新明确的作者约束优先。点击 **本轮保存的记忆** 可查看摘要。

选用 DeepSeek 时，可以勾选 **使用 DeepSeek 补充本轮语义摘要**。该选项最多为本轮增加一次请求，只归纳讨论过的方案和未解决事项，调用用量单独展示。摘要失败后，完整问答及本地记忆仍可查看，可以点击 **补做本轮摘要**。

发送前优先保留当前问题、作者约束和关键证据。接近预算时，把较早的消息、滚动摘要和重复工具结果重新组装成较小的资料包。深度模式保留已查节点、关键连接和出处，并按实际发送的证据重新校验引用。接口明确报告上下文超限时，如果模型次数和累计预算还有余量，自动压缩后重试一次。普通模式仍最多 3 次问答模型调用，深度模式仍最多 5 次，超限重试计入这些额度。

在 **依据、范围与调用用量** 可查看每次压缩的前后估算与触发原因。发送预算使用保守的 UTF-8 字节估算并预留输出空间，实际 token 用量来自接口回报。
